word-roots
简介 / Introduction
中文：word-roots 是一个轻量级的英语词根学习工具，帮助你通过词根、前缀和后缀快速扩大词汇量。它包含常见拉丁语和希腊语词根的整理与例词解析。
English: word-roots is a lightweight English word-root learning tool that helps you quickly expand your vocabulary through roots, prefixes, and suffixes. It includes curated common Latin and Greek roots with example word breakdowns.
特性 / Features
中文：
📖 收录 常用词根（拉丁语 & 希腊语）
🔍 例词拆解：每个词根附带词源解析
🌐 支持中英双语界面
English:
📖 curated common roots (Latin & Greek)
🔍 Example word breakdowns with etymology for each root
🌐 Bilingual (Chinese & English) support
